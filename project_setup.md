\# Project Setup - Mobile Store Management System\## 1. Platforms\- \*\*Desktop App:\*\* Python + PyQt (GUI) مع دعم Offline.\- \*\*Web App:\*\* Django (Backend) + React (Frontend).\- \*\*Mobile App:\*\* Flutter (Android/iOS).\- \*\*Database:\*\* Firebase Firestore كبداية، PostgreSQL عند التوسع.\- \*\*API:\*\* REST موحد يربط Desktop/Web/Mobile.\- \*\*Containerization:\*\* Docker لتوزيع موحد.\- \*\*CI/CD:\*\* GitHub Actions للتحديثات الأوتوماتيك.\---\## 2. Database Schema\### Users\- id, name, email, phone\- role (admin/user)\- created\_at, updated\_at\### Licenses\- id, user\_id, license\_key\- start\_date, end\_date\- type (trial/paid)\- status (active/expired)\### Devices\- id, user\_id, hardware\_id/mac\_address\- license\_id\### Tokens (Offline License)\- id, device\_id\- token\_encrypted\- last\_online\_check\- expiry\_date\### Inventory\- id, name, brand, model\- purchase\_price, sale\_price\- status (available/sold)\- created\_at\### Sales\- id, device\_id, customer\_id\- sale\_price, profit, date\### Repairs\- id, customer\_id\- device\_info, issue\_description\- repair\_cost, customer\_payment, profit\- status (pending/completed)\- created\_at, updated\_at\### Customers\- id, name, phone, email\- created\_at\---\## 3. License System\- \*\*Online Check:\*\* أول تشغيل يتحقق من السيرفر ويربط الكود بالجهاز.\- \*\*Offline Token:\*\* تخزين Token مشفر محليًا (AES/RSA).\- \*\*Grace Period:\*\* تشغيل Offline لمدة 7 أيام، بعدها لازم Online Check.\- \*\*Trial Mode:\*\* فترة تجريبية (14 يوم).\- \*\*Remote Kill:\*\* السيرفر يقدر يقفل نسخة مسروقة عند أول اتصال.\---\## 4. Backup \& Updates\- \*\*Backup:\*\* أوتوماتيك يومي على Firebase + نسخة محلية.\- \*\*Updates:\*\* Patch/Migration Scripts تطبق بدون فقد بيانات.\- \*\*Digital Signature:\*\* كل تحديث موقع رقميًا لمنع التلاعب.\---\## 5. Reports\- \*\*Financial Reports:\*\* رأس المال، المبيعات، الأرباح.\- \*\*Inventory Reports:\*\* الأجهزة المتاحة، المباعة، قيمتها.\- \*\*Customer Reports:\*\* العملاء الأكثر تكرارًا، متوسط إنفاقهم.\- \*\*Repair Reports:\*\* الأعطال الأكثر شيوعًا، تكلفة الإصلاحات.\- \*\*Marketing Reports:\*\* الأجهزة الأكثر طلبًا، مواسم الذروة، العملاء المستهدفين.\---\## 6. Integration\- \*\*Firebase:\*\* Authentication + Firestore + Hosting + Notifications.\- \*\*Docker:\*\* تشغيل موحد لكل المنصات.\- \*\*GitHub Actions:\*\* CI/CD للتحديثات الأوتوماتيك.\- \*\*Analytics:\*\* Firebase Analytics + Power BI للتسويق الرقمي.\---\## 7. Security\- \*\*RBAC:\*\* Role-Based Access Control (Admin/User).\- \*\*Encryption:\*\* AES/RSA للـ Tokens والبيانات الحساسة.\- \*\*Logs:\*\* مراقبة الاستخدام ومحاولات الدخول.\- \*\*Remote Kill:\*\* إيقاف النسخ غير الشرعية.\---\## 8.
